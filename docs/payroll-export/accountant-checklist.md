# ממשק שכר לשקלולית — מה נדרש מהרואה חשבון

עודכן: 27.09.2026. בן נמצא אצל הרו"ח עם הרשימה הזו.

## סטטוס הפרויקט

- **מה נבנה:** שכבת המקור (`server/src/services/payrollExport/sourceLayer.js`) מוזגה ל-main ובאוויר. הופכת חודש שכר לצורה קנונית יציבה + ביקורת פר-עובד (`toCanonicalEmployee` / `auditEmployee` / `buildExportSource`). 9 בדיקות: `npm run test:export-source`. לא מחוברת לשום מסך/route.
- **עיקרון:** לא משכפלים חישוב שכר — כל מספר נמשך מהשדות שהמסך וה-PDF לרו"ח כבר קוראים (`getMonth`/`fetchMonthData` ב-`payrollMonth.controller.js`).
- **מה חסר:** המפרט והקודים שברשימה למטה. ברגע שיש — בונים adapter + exporter (כנראה קידוד Windows-1255, תלוי במפרט) + חיבור למסך.

## א. מסמכים לבקש (חוסם — בלי זה תקועים)

1. **מפרט קובץ "קליטת תנועות" של שקלולית** — המסמך הרשמי של טמל על מבנה קובץ הקליטה. אם אין לרו"ח — לבקש מהתמיכה של טמל, או לפחות צילום של מסך הקליטה.
2. **קובץ דוגמה אמיתי** שנקלט בהצלחה (אפשר מלקוח אחר, בלי שמות).
3. **טבלת קודי רכיבים** — הקוד המספרי בשקלולית לכל רכיב שלנו:

| הרכיב אצלנו | שדה בשכבת המקור | קוד בשקלולית |
|---|---|---|
| שכר בסיס (שעתי) | `earnings.base_salary` | |
| שכר בסיס (גלובלי) | `earnings.base_salary` | |
| השלמת שכר | `earnings.salary_completion` | |
| נסיעות | `earnings.travel` | |
| הבראה | `earnings.recreation` | |

## ב. שאלות שחייבות תשובה

4. **כמויות או סכומים?** לכל רכיב — האם שקלולית מקבלת כמות (שעות/ימים) ומחשבת בעצמה, או סכום סופי בש"ח? קריטי עבור: שעות רגילות, ש"נ 125%, ש"נ 150%, ימי מחלה, ימי חופשה, ימי חג. שכבת המקור מחזיקה את שניהם (`quantities` וגם `earnings`).
5. **זיהוי עובד** — לפי ת"ז או לפי מספר עובד פנימי בשקלולית? אם מספר עובד — צריך את רשימת המספרים אצלו להתאמה מול `employee_number` שלנו.
6. **פרטי בנק** — עוברים בקובץ, או מנוהלים ידנית בשקלולית (ואז לא חלק מהממשק)?
7. **עובדי נטו** (`salary_is_net`) — מי עושה גילום: הרו"ח בשקלולית, או סימון בקובץ?
8. **הוראות בטקסט חופשי** (`directives.*` — מקדמות, הערות) — איך לקבל: דוח נלווה לצד הקובץ?
9. **פרילנסרים** — מוחרגים מהקובץ (`skipped`). לאשר שנכון גם אצלו.

## ג. פרטים טכניים

10. **סוג קובץ** — אקסל / CSV / טקסט ברוחב קבוע? **קידוד עברית** (Windows-1255 או UTF-8)?
11. **מבנה** — קובץ אחד לחודש? שורת כותרת? שורת סיכום?

## ד. סגירת תהליך

12. **חודש ניסיון:** קובץ על חודש ששולם (למשל 08/2026) → קליטה בשקלולית → השוואה מול מה ששולם בפועל. רק אחרי התאמה מלאה עוברים לשוטף.
13. **תפעול שוטף:** איך מועבר הקובץ (מייל?) ועד איזה תאריך בחודש.

## מה שהתקבל — לתעד כאן

כשמגיעות תשובות: לעדכן את הקובץ הזה (או להוסיף את מסמכי המפרט לתיקייה `docs/payroll-export/`), לשמור ולדחוף — כדי שכל מחשב יראה. אחר כך: בניית adapter לפי המפרט.
