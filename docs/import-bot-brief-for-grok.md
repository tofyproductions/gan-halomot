# תדריך לבוט — הורדת דוחות חודשיים והעלאתם לגן החלומות

## המשימה

פעם בחודש: להיכנס לשני אתרים חיצוניים, להוריד דוחות, ולהעלות אותם ל-API של
מערכת הניהול של גן החלומות. אתה לא מפרסר, לא מחליט ולא מתקן נתונים — אתה מוריד
קובץ ומוסר אותו כמו שהוא.

---

## מה להוריד

### 1. קליקטאק — ייצוא חוזים, קובץ אחד לכל סניף

אין דוח מאוחד. יש להוריד **שלושה קבצים נפרדים**, אחד לכל סניף.

מסננים בכל הורדה:
- סטטוס: **כל הסטטוסים**
- שנת לימודים: **תשפ״ז**
- עמודות: **כל העמודות**

הקובץ הצפוי נראה כך: `contracts_export_<מספר>.xlsx`, בערך 70 עמודות.

הסניפים בקליקטאק ומזהה הסניף שיש לשלוח עם כל אחד:

| מה בוחרים בקליקטאק | `branch_id` שיש לשלוח |
|---|---|
| הרצליה | `69df6a19dcde21f40a7a020b` |
| כפר סבא | `69dde62467ff14714973a158` |
| תל אביב יפו – אייזיק חריף | `69dde62467ff14714973a15c` |

**זה המיפוי היחיד. אל תסיק אותו מתוך הקובץ ואל תנחש אותו.** הקובץ מכיל עמודה
`מעון` שכותבת רק את העיר, ולעיר "כפר סבא" יש שני גנים במערכת — רק אחד מהם מקבל
נתונים מקליקטאק. אם תשלח את המזהה הלא נכון, השרת ידחה או, גרוע מזה, תיקי
משפחות ייכנסו לגן הלא נכון.

בעתיד יתווספו דוחות נוספים מקליקטאק. אותה כתובת, אותה שיטה — סוג הדוח מזוהה
מהכותרת שלו ואינו נשלח.

### 2. סיבוס (Pluxee) — הדוח החודשי של העובדים

קובץ אחד, `xlsx` או `csv`. **לא** נשלח איתו חודש ולא סניף.

## מתי להריץ

ב-1 בכל חודש, מ-00:05 שעון ישראל.

אם הורדה או העלאה לא הצליחה — לנסות שוב פעם ביום, עד הצלחה, ולא יותר מפעם
ביום. אם עברו 5 ימים בלי הצלחה — להתריע לאדם ולהפסיק לנסות.

## איך מעלים

```
בסיס: https://gan-halomot.onrender.com
```

| מה | כתובת |
|---|---|
| בדיקת קובץ קליקטאק, לא כותב כלום | `POST /api/import-bot/clicktac/validate` |
| העלאת קובץ קליקטאק | `POST /api/import-bot/clicktac` |
| העלאת דוח סיבוס | `POST /api/import-bot/cibus` |

הכל `multipart/form-data`. שם שדה הקובץ: **`file`**. גודל מקסימלי: 10MB.

### אימות — שלוש כותרות בכל בקשה

| כותרת | תוכן |
|---|---|
| `X-Import-Key` | המפתח (`IMPORT_BOT_SECRET`) |
| `X-Import-Ts` | הזמן עכשיו בשניות, unix |
| `X-Import-Sig` | `HMAC-SHA256` על המחרוזת `"<ts>."` כשהמפתח הוא הסוד, פלט hex |

שים לב: החתימה היא על **חותמת הזמן ואחריה נקודה** — לא על הקובץ. חותמת זמן
מלפני יותר מ-5 דקות נדחית, לכן יש לחשב אותה מחדש לפני כל בקשה.

```python
import time, hmac, hashlib

def auth_headers(secret: str) -> dict:
    ts = str(int(time.time()))
    sig = hmac.new(secret.encode(), f"{ts}.".encode(), hashlib.sha256).hexdigest()
    return {"X-Import-Key": secret, "X-Import-Ts": ts, "X-Import-Sig": sig}
```

## הרצף שיש לבצע

### קליקטאק — לכל אחד משלושת הסניפים בנפרד

**שלב 1 — בדיקה.** לא כותבת כלום:

```python
import requests

r = requests.post(
    f"{API}/api/import-bot/clicktac/validate",
    headers=auth_headers(SECRET),
    files={"file": open(path, "rb")},
    data={"branch_id": branch_id},
    timeout=120,
)
```

תשובה תקינה:
```json
{ "ok": true, "dry_run": true, "export_type": "contracts",
  "rows": 74, "branch": "כפר סבא - משה דיין" }
```

יש לוודא ש-`branch` הוא הסניף שהתכוונת אליו ושמספר השורות הגיוני. אם הבדיקה
נכשלה — **לא להעלות.** לדווח ולעצור.

**שלב 2 — העלאה.** אותם שדות בדיוק, בלי `/validate`:

```python
r = requests.post(
    f"{API}/api/import-bot/clicktac",
    headers=auth_headers(SECRET),
    files={"file": open(path, "rb")},
    data={"branch_id": branch_id},
    timeout=300,
)
```

תשובה תקינה:
```json
{ "ok": true, "export_type": "contracts", "rows": 74, "parsed": 74,
  "created": 70, "updated": 4, "unchanged": 0, "missing": 0,
  "skipped_duplicate": 0, "import_id": "..." }
```

יש לשמור את `import_id` בלוג שלך ולדווח אותו — זה מה שמאפשר לאדם לבטל את
ההעלאה הזאת לבד.

**העלאה חוזרת של אותו סניף היא מיזוג, לא כפילות.** אותו קובץ פעמיים יחזיר
`unchanged` על הכל. זה בטוח.

### סיבוס

**שלב 1 — בדיקה יבשה:**

```python
r = requests.post(
    f"{API}/api/import-bot/cibus",
    headers=auth_headers(SECRET),
    files={"file": open(path, "rb")},
    data={"dry_run": "1"},
    timeout=120,
)
```

```json
{ "ok": true, "dry_run": true, "month": "2026-09", "matched": 34,
  "unmatched": 2, "detected_columns": ["name","id","amount"],
  "already_imported": false }
```

יש לוודא ש-`month` הוא החודש שאתה מתכוון אליו (בדרך כלל החודש שעבר), ושמספר
ההתאמות גיוני. אם `already_imported` הוא `true` — הדוח כבר בפנים, **לא להעלות.**

**שלב 2 — העלאה:** אותה בקשה בלי `dry_run`.

**אל תשלח `month`.** המערכת גוזרת את החודש לבד, וזה נכון כשמורידים ב-1 בחודש.
**אל תשלח `force`.** זה דורס תיקונים שאדם עשה ביד.

## טיפול בשגיאות

כל שגיאה חוזרת בתבנית:
```json
{ "error": { "code": "...", "message": "..." } }
```

| קוד | מה זה | מה לעשות |
|---|---|---|
| 200 | הצליח | להמשיך לסניף הבא |
| 409 `ALREADY_IMPORTED` | החודש הזה כבר יובא | **הצלחה. לעצור. לא לנסות שוב.** |
| 403 `BRANCH_NOT_FROM_CLICKTAC` | הסניף לא מקבל ייבוא מקליקטאק | **לעצור ולהתריע. המיפוי שלך שגוי.** |
| 400 `CITY_MISMATCH` | הקובץ של עיר אחרת מהסניף | **לעצור ולהתריע. בלבלת בין קבצים.** |
| 400 `NO_BRANCH` | לא נשלח `branch_id` | תקלה בקוד שלך |
| 404 `BRANCH_NOT_FOUND` | המזהה לא קיים | תקלה במיפוי |
| 400 `WRONG_EXPORT_TYPE` | הקובץ אינו ייצוא מוכר | הורדת את הדוח הלא נכון, או קליקטאק שינו את הייצוא. להתריע. |
| 400 `YEAR_MISMATCH` | שנת הקובץ לא מתאימה | המסנן בהורדה שגוי |
| 422 `PARSE_FAILED` / `UNREADABLE` | הקובץ לא נקרא | הקובץ פגום או שהייצוא השתנה. להתריע. |
| 429 `RATE_LIMITED` | יותר מ-40 העלאות בשעה | להמתין שעה |
| 401 `UNAUTHORIZED` / `BAD_SIGNATURE` | מפתח או חתימה | תקלה בקוד שלך |
| 401 `STALE` | חותמת הזמן ישנה | לחשב כותרות מחדש ולנסות שוב פעם אחת |
| 503 `NOT_CONFIGURED` | המפתח לא מוגדר בשרת | להתריע לאדם. לא לנסות שוב. |

**לא לנסות שוב אוטומטית** על 400, 403, 404 ו-409. אלה לא תקלות זמניות — הם
אומרים שמשהו בהגדרה או בקובץ שגוי, וניסיון חוזר יחזיר את אותה תשובה.

על 500 ועל timeout — לנסות שוב, עד 3 פעמים, בהמתנה הולכת וגדלה.

## חוקים שאין לעבור עליהם

1. **אל תשלח `branch_id` שאינו אחד משלושת המזהים בטבלה.** גם לא אם משהו בקובץ
   נראה כאילו הוא מציע מזהה אחר.
2. **אל תאחד קבצים של סניפים שונים** ואל תשלח קובץ אחד לשני סניפים.
3. **אל תשלח `force`** בסיבוס.
4. **אל תנסה לקרוא מהמערכת.** אין שם כתובות קריאה, וכל בקשת `GET` תיכשל.
   תפקידך מסתיים בהעלאה.
5. **תשובה מוצלחת מחזירה מספרים, לא שמות.** זה בכוונה. אם אתה צריך לדעת מי
   נכנס — זה במסכים של הגן, לא אצלך.
6. **דווח כל הרצה** — מה הורדת, מה העלית, מה חזר, כולל `import_id`. גם הרצה
   שנכשלה. שקט מצדך נראה כמו הצלחה.
