## שלב 2 — שכבת החלטות

אוסף חדש `ReconcileDecision`, מפתח ייחודי `(branch_id, academic_year, id_number)`. נפרד משני הקבצים → אף העלאה לא נוגעת בו.

```
note: String                       // הערה חופשית
verdict_override: null | 'private' // "בגן ללא תמ"ת" (רפאל), עם reason
resolutions: [{
  code,                            // קוד החריגה שנסגרה
  choice,                          // 'tmt' | 'clicktac' | 'custom' | 'ok'
  value,                           // הערך שנבחר (שם / טלפון / תאריך)
  snapshot,                        // ערכי שני הצדדים ברגע הסגירה
  by, at
}]
parent_overrides: { parent1: {name, phone}, parent2: {...} }
```

- חריגה עם `resolution` מוסתרת מהטבלה. אם ערכי הקבצים השתנו מאז ה-`snapshot` → החריגה חוזרת בכתום עם "השתנה מאז שסגרת" והאדם בוחר מחדש.
- `parent_overrides` גוברים בתצוגה, בייצוא ובקליטה לרישום, עם תג "לתקן בקליקטאק". נמחקים לבד כשהקובץ תואם.
- חלון הפרטים מקבל: הערה, "בגן ללא תמ"ת", כפתור סגירה ליד כל חריגה עם בחירה, עריכת שני ההורים.
- **ארכיון**: `gone` מוסתר; מסנן "ארכיון (30 יום)"; משימה יומית מוחקת שורות `gone` מעל 30 יום משני האוספים.
